1. product.objects.all() --> each row becomes python object 
2. product.objects.values() --> returns data... in the form of dictionary 
3. Product.objects.values("name","price") --> returns specific columns.

Why Use values()?

Imagine an API returning 100,000 products.

Creating 100,000 Python model objects consumes more memory than returning plain dictionaries.

This is one reason serializers and reporting endpoints often start with values().
